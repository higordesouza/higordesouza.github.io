# 🍕 Foodly - Página Web de Comida a Domicilio

Este proyecto es una página web responsiva para un servicio de pedidos de comida a domicilio, inspirada en un diseño moderno y visualmente atractivo.

---

## 🚀 Funcionalidades

- Página de inicio con mensaje de bienvenida y CTA principal.
- Sección de categorías destacadas con tarjetas visuales.
- Guía paso a paso de cómo hacer pedidos.
- Formulario de contacto funcional.
- Diseño adaptado para móviles y tablets.
- Construido con `HTML` + `CSS` usando `Flexbox` y `Grid`.
